🚀 WB SLOTS - БЫСТРЫЙ СТАРТ
================================

Для запуска проекта выполните следующие шаги:

1️⃣ ПЕРВЫЙ ЗАПУСК (настройка):
   Дважды кликните: wb-slots-manager.bat
   Выберите: 1. Первоначальная настройка

2️⃣ ОБЫЧНЫЙ ЗАПУСК:
   Дважды кликните: wb-slots-manager.bat
   Выберите: 3. Быстрый запуск сервисов

3️⃣ ОСТАНОВКА:
   Дважды кликните: wb-slots-manager.bat
   Выберите: 4. Остановка всех сервисов

📋 ТРЕБОВАНИЯ:
- Node.js 20.x+ (https://nodejs.org/)
- Docker Desktop (https://www.docker.com/products/docker-desktop/)

🌐 ПОСЛЕ ЗАПУСКА:
- Frontend: http://localhost:3000
- Backend: http://localhost:3001

❓ ПРОБЛЕМЫ С DOCKER?
- Запустите: wb-slots-manager.bat → 9. Исправить проблемы Docker
- Или используйте: wb-slots-manager.bat → 10. Локальная разработка
