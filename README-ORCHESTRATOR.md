# WB Slots - Скрипт-оркестратор для Windows

Этот набор скриптов позволяет легко развернуть и запустить проект WB Slots на локальном компьютере Windows одним кликом.

## 📋 Системные требования

Перед использованием убедитесь, что у вас установлены:

- **Node.js** (LTS версия) - [Скачать](https://nodejs.org/)
- **Docker Desktop** - [Скачать](https://www.docker.com/products/docker-desktop/)
- **Git** (опционально) - [Скачать](https://git-scm.com/)

## 🚀 Быстрый старт

### 1. Первоначальная настройка

Запустите скрипт для первоначальной настройки проекта:

```batch
setup-project.bat
```

Этот скрипт:
- Проверит все системные требования
- Установит все зависимости
- Создаст .env файл из шаблона
- Запустит Docker контейнеры
- Применит миграции базы данных
- Заполнит базу тестовыми данными

### 2. Запуск проекта

После настройки используйте основной оркестратор:

```batch
start-project.bat
```

Или для быстрого запуска только сервисов:

```batch
start-services.bat
```

### 3. Остановка проекта

Для остановки всех сервисов:

```batch
stop-services.bat
```

## ⚙️ Настройка

### Переменные окружения

После первого запуска `setup-project.bat` будет создан файл `.env` в папке `wb-slots`. Отредактируйте его под ваши нужды:

```env
# База данных
DATABASE_URL="postgresql://postgres:password@localhost:5432/wb_slots?schema=public"

# Redis
REDIS_URL="redis://localhost:6379"

# JWT секрет (ОБЯЗАТЕЛЬНО измените в продакшене!)
JWT_SECRET="your-super-secret-jwt-key-here-change-in-production"

# Ключ шифрования (ОБЯЗАТЕЛЬНО измените в продакшене!)
ENCRYPTION_KEY="your-32-byte-base64-encryption-key-here"

# Telegram Bot (опционально)
TELEGRAM_BOT_TOKEN=""
```

### Порты

По умолчанию используются следующие порты:

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:3001
- **PostgreSQL**: localhost:5432
- **Redis**: localhost:6379

Если порты заняты, измените их в соответствующих конфигурационных файлах.

## 🎛️ Основной оркестратор

`start-project.bat` предоставляет интерактивное меню:

```
========================================
          МЕНЮ УПРАВЛЕНИЯ
========================================
1. Полная установка и запуск проекта
2. Только запуск проекта (без установки)
3. Остановка всех сервисов
4. Перезапуск проекта
5. Просмотр логов
6. Очистка и переустановка
7. Выход
========================================
```

### Опции меню:

1. **Полная установка** - Устанавливает зависимости, запускает Docker, применяет миграции
2. **Только запуск** - Быстро запускает уже настроенный проект
3. **Остановка** - Останавливает все сервисы и процессы
4. **Перезапуск** - Останавливает и заново запускает проект
5. **Просмотр логов** - Открывает логи Docker контейнеров
6. **Очистка** - Полная переустановка с очисткой данных
7. **Выход** - Завершение работы

## 🔧 Ручное управление

Если автоматические скрипты не работают, вы можете управлять проектом вручную:

### Запуск Docker контейнеров
```batch
cd wb-slots
docker-compose up -d
```

### Установка зависимостей
```batch
# Frontend
cd wb-slots
npm install

# Backend
cd wb-slots/backend
npm install
```

### Применение миграций
```batch
cd wb-slots
npx prisma db push
npx prisma generate
```

### Запуск сервисов
```batch
# Frontend
cd wb-slots
npm run dev

# Backend (в отдельном терминале)
cd wb-slots/backend
npm run start:dev

# Worker (в отдельном терминале)
cd wb-slots
npm run worker
```

## 🐛 Решение проблем

### Docker не запускается
- Убедитесь, что Docker Desktop запущен
- Проверьте, что порты 5432 и 6379 свободны
- Перезапустите Docker Desktop

### Ошибки базы данных
- Проверьте, что PostgreSQL контейнер запущен: `docker ps`
- Проверьте логи: `docker-compose logs postgres`
- Попробуйте пересоздать базу: `docker-compose down -v && docker-compose up -d`

### Ошибки зависимостей
- Удалите `node_modules` и `package-lock.json`
- Выполните `npm install` заново
- Проверьте версию Node.js: `node --version`

### Порты заняты
- Остановите другие приложения, использующие порты 3000, 3001, 5432, 6379
- Или измените порты в конфигурационных файлах

## 🔄 Обновление проекта

Для обновления проекта:

1. Остановите все сервисы: `stop-services.bat`
2. Обновите код из репозитория
3. Запустите полную установку: `start-project.bat` → опция 1
