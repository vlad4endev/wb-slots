## [1.0.0] - 2025-01-09

### Добавлено
- 🎉 Первый релиз проекта WB Slots
- 🔐 Система аутентификации с JWT
- 👥 Мультипользовательская поддержка
- 📦 Управление токенами WB API
- 🏢 Настройка складов и предпочтений
- 🎯 Создание и управление задачами поиска
- 📊 Мониторинг выполнения задач
- 🔔 Система уведомлений
- 🗄️ База данных PostgreSQL с Prisma
- ⚡ Redis для очередей и кэширования
- 🎨 Современный UI с TailwindCSS
- 📱 Адаптивный дизайн
- 🐳 Docker поддержка
- 📚 Подробная документация

### Технические детали
- **Frontend**: Next.js 15.5.2 + TypeScript + TailwindCSS
- **Backend**: Next.js API Routes + Prisma ORM
- **База данных**: PostgreSQL 15 + Redis 7
- **Аутентификация**: JWT + bcryptjs
- **Очереди**: BullMQ + Redis
- **Контейнеризация**: Docker + Docker Compose

## Формат версий

Мы используем [Semantic Versioning](https://semver.org/):

- **MAJOR** версия когда делаем несовместимые изменения API
- **MINOR** версия когда добавляем функциональность обратно совместимым способом
- **PATCH** версия когда делаем обратно совместимые исправления ошибок
