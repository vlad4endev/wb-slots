# 🤖 Руководство по доступу к настройкам Telegram бота

## 📍 Где найти настройки Telegram бота

### 1. 🏠 Главная страница настроек
**Путь:** `/settings`

**Как найти:**
1. Перейдите в раздел "Настройки системы"
2. Найдите карточку "Telegram уведомления"
3. Нажмите кнопку "Настроить Telegram" для базовых настроек
4. Или нажмите кнопку "Настройки Telegram" в правом верхнем углу для расширенных настроек

### 2. 🔧 Расширенные настройки Telegram
**Путь:** `/settings/telegram`

**Как найти:**
1. Перейдите в раздел "Настройки системы" (`/settings`)
2. Нажмите кнопку "Настройки Telegram" в правом верхнем углу
3. Или перейдите напрямую по ссылке `/settings/telegram`

## 🎯 Что можно настроить

### 👤 Пользовательские настройки
- **Chat ID** - ваш идентификатор в Telegram
- **Включение/отключение** уведомлений
- **Тестирование** уведомлений

### 🔧 Настройки разработчика (только для DEVELOPER/ADMIN)
- **Токен бота** - настройка токена от @BotFather
- **Шаблоны уведомлений** - управление шаблонами сообщений
- **Статус бота** - проверка работоспособности

## 🚀 Быстрый доступ

### Кнопки быстрого доступа:
1. **В заголовке страницы настроек** - кнопка "Настройки Telegram"
2. **В карточке Telegram** - кнопка "Открыть настройки"
3. **Прямая ссылка** - `/settings/telegram`

## 🔐 Требования доступа

### Пользовательские настройки
- ✅ Любой авторизованный пользователь

### Настройки разработчика
- ✅ Роль `DEVELOPER` или `ADMIN`
- ❌ Обычные пользователи не видят эту вкладку

## 📱 Мобильная версия

Все настройки адаптированы для мобильных устройств и доступны через:
- Мобильный браузер
- Telegram Web App
- PWA (Progressive Web App)

## 🆘 Если не видите настройки

1. **Проверьте авторизацию** - войдите в систему
2. **Обновите страницу** - нажмите F5 или Ctrl+R
3. **Проверьте роль** - для админских настроек нужна роль DEVELOPER/ADMIN
4. **Очистите кэш** - Ctrl+Shift+R для полной перезагрузки

## 📞 Поддержка

Если настройки не отображаются:
1. Проверьте консоль браузера на ошибки (F12)
2. Убедитесь, что сервер запущен
3. Проверьте подключение к интернету
4. Обратитесь к разработчику
