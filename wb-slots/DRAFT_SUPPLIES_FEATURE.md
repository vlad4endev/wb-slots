# Загрузка поставок со статусом "черновик"

## Описание

Реализована возможность загрузки поставок со статусом "черновик" при создании задач. Теперь при нажатии в форме создания задачи система загружает поставки с API `https://supplies-api.wildberries.ru/api/v1/supplies`, используя токен из настроек пользователя.

## Изменения

### Backend (NestJS)

#### 1. `backend/src/supplies/supplies.service.ts`
- Добавлена поддержка фильтрации по статусу `draft`
- Поставки фильтруются по следующим критериям:
  - `status === 'DRAFT'`
  - `status === 'черновик'`
  - `status.toLowerCase().includes('draft')`

#### 2. `backend/src/supplies/supplies.controller.ts`
- Обновлена документация API для поддержки статуса `draft`
- Параметр `status` теперь принимает значения: `active`, `draft`, `all`

### Frontend (Next.js)

#### 1. `src/components/create-task-modal.tsx`
- Изменен параметр `status` с `active` на `draft` в запросе к API
- Обновлено логирование для отображения количества загруженных поставок-черновиков

## API Endpoints

### GET `/api/supplies`
Параметры:
- `limit` (optional): Количество поставок (по умолчанию 50)
- `offset` (optional): Смещение для пагинации (по умолчанию 0)
- `status` (optional): Статус поставок (`active`, `draft`, `all`)

### Примеры запросов

```bash
# Получить поставки со статусом "черновик"
GET /api/supplies?status=draft&limit=100

# Получить активные поставки (как было раньше)
GET /api/supplies?status=active&limit=100

# Получить все поставки
GET /api/supplies?status=all&limit=100
```

## Использование

1. Пользователь должен иметь настроенный токен категории `SUPPLIES` в настройках
2. При открытии формы создания задачи и включении автобронирования автоматически загружаются поставки со статусом "черновик"
3. Пользователь может выбрать нужную поставку из выпадающего списка

## Тестирование

Для тестирования функциональности используйте скрипт:
```bash
node test-draft-supplies.js
```

Скрипт проверяет:
- Работу API endpoint
- Корректность фильтрации по статусу "черновик"
- Структуру ответа
- Наличие ошибок

## Требования

- Токен Wildberries API категории `SUPPLIES`
- Настроенные настройки пользователя
- Доступ к API `https://supplies-api.wildberries.ru/api/v1/supplies`

## Статусы поставок

Поддерживаемые статусы для фильтрации:
- `DRAFT` - черновик (английский)
- `черновик` - черновик (русский)
- Любой статус, содержащий "draft" (регистронезависимо)

## Логирование

В консоли отображается:
- Количество загруженных поставок-черновиков
- Ошибки при загрузке
- Детали API ответов
