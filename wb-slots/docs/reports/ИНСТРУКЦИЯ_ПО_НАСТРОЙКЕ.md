# 🚀 Инструкция по настройке WB Slots

## 📋 Что нужно для работы системы

### 1️⃣ **Для ПОИСКА слотов** (обязательно)

#### Требуется: **Токен API (SUPPLIES)**

**Как получить:**
1. Откройте https://seller.wildberries.ru/supplier-settings/access-to-api
2. Нажмите "Создать новый токен"
3. Выберите права: **"Поставки"** или **"Все"**
4. Скопируйте токен (показывается один раз!)

**Как добавить в систему:**
1. Откройте **Настройки** → **Токены API** (`/settings`)
2. В разделе "Токены API Wildberries"
3. Вставьте токен
4. Выберите категорию: **SUPPLIES**
5. Нажмите "Добавить токен"

**Что работает с токеном:**
- ✅ Поиск доступных слотов
- ✅ Получение списка складов
- ✅ Получение списка поставок

---

### 2️⃣ **Для АВТОБРОНИРОВАНИЯ** (опционально)

#### Требуется: **WB Сессия (браузер)**

**Как создать:**
1. Откройте **WB Auth** (`/wb-auth`)
2. Выберите метод авторизации:
   - **Popup** - быстрая авторизация в новом окне
   - **Enhanced** - авторизация с расширенными возможностями
3. Введите номер телефона (начинается с +7)
4. Введите код из СМС
5. Дождитесь подтверждения авторизации

**Что работает с WB сессией:**
- ✅ Автоматическое бронирование найденных слотов
- ✅ Заполнение формы бронирования
- ✅ Отправка бронирования на WB

**Срок действия:** до 7 дней (затем требуется повторная авторизация)

## 🎯 Сценарии использования

### 🔍 **Только поиск слотов** (БЕЗ автобронирования)

**Что нужно:**
- ✅ Токен API (SUPPLIES)
- ❌ WB Сессия НЕ нужна

**Как использовать:**
1. Добавьте токен SUPPLIES в настройках
2. Создайте задачу поиска:
   - Укажите название
   - Выберите склады
   - Выберите тип поставки
   - Настройте период и коэффициенты
   - **НЕ включайте** "Автобронирование"
3. Запустите задачу
4. Система будет искать слоты и показывать результаты

---

### ⚡ **Поиск + Автобронирование** (ПОЛНЫЙ функционал)

**Что нужно:**
- ✅ Токен API (SUPPLIES)
- ✅ WB Сессия (браузер)

**Как использовать:**
1. Добавьте токен SUPPLIES в настройках
2. Авторизуйтесь через WB Auth (создайте WB сессию)
3. Создайте задачу поиска:
   - Укажите название
   - Выберите склады
   - Выберите тип поставки
   - Настройте период и коэффициенты
   - ✅ **Включите** "Автобронирование"
   - Укажите номер поставки (вручную или выберите из списка)
4. Запустите задачу
5. Система будет:
   - 🔍 Искать подходящие слоты
   - ⚡ Автоматически бронировать их
   - 📧 Отправлять уведомления (если настроен Telegram)

## ⚠️ Частые ошибки и решения

### ❌ **Ошибка: "No active supplies token found"**

**Причина:** Нет токена API или он неактивен

**Решение:**
1. Проверьте настройки → Токены API
2. Убедитесь что токен категории SUPPLIES активен (зелёная галочка)
3. Если токена нет - добавьте новый
4. Если токен есть но неактивен - удалите и добавьте новый

---

### ❌ **Ошибка: "401 Unauthorized - token invalid or expired"**

**Причина:** Токен API истёк или был отозван на стороне WB

**Решение:**
1. Перейдите на https://seller.wildberries.ru/supplier-settings/access-to-api
2. Удалите старый токен (если он есть)
3. Создайте новый токен с правами "Поставки"
4. Добавьте новый токен в систему (Настройки → Токены API)
5. Создайте новую задачу или перезапустите остановленную

---

### ❌ **Автобронирование не работает** (кнопка неактивна)

**Причина:** Нет активной WB сессии

**Решение:**
1. Перейдите в WB Auth (`/wb-auth`)
2. Авторизуйтесь заново через Wildberries
3. Вернитесь к созданию задачи
4. Кнопка автобронирования станет активной

---

### ❌ **"No notification channels configured"**

**Причина:** Не настроен Telegram бот для уведомлений

**Решение (опционально):**
1. Настройте Telegram бота в настройках
2. Привяжите свой Telegram ID
3. Теперь будете получать уведомления о найденных слотах

**Примечание:** Это не критично - система работает и без уведомлений

## 🔄 Проверка статуса

### **Проверка токена API:**
```
Настройки → Токены API → 
Должен быть токен с:
- Категория: SUPPLIES
- Статус: ✅ Активен (зелёная галочка)
```

### **Проверка WB сессии:**
```
WB Auth → Sessions →
Должна быть сессия с:
- Status: Active
- Phone: ваш номер
- Last Active: недавняя дата
```
