# 🏗️ Унифицированная архитектура WB Slots

## 📋 Обзор

Проект был полностью рефакторен для устранения дублирования кода и создания единой архитектуры. Все сервисы теперь используют общие интерфейсы и управляются через централизованный менеджер.

## ✨ Что изменилось

### ❌ Удалено (дублирующийся код)
- **4 версии сервисов поиска слотов** → **1 унифицированный**
- **4 версии сервисов автобронирования** → **1 унифицированный**  
- **4 версии сервисов уведомлений** → **1 унифицированный**
- **2 версии WB API клиентов** → **1 унифицированный**
- **Дублирующиеся API endpoints** → **Единый API**

### ✅ Добавлено (новая архитектура)
- **Единые интерфейсы** для всех сервисов
- **Базовый класс** с общей функциональностью
- **Менеджер сервисов** для централизованного управления
- **Единая точка входа** для всего приложения
- **Автоматический мониторинг** здоровья системы

## 🔧 Основные компоненты

### 1. Единые интерфейсы (`unified-interfaces.ts`)
- `IBaseService` - базовый интерфейс для всех сервисов
- `ISlotSearchService` - интерфейс поиска слотов
- `IAutoBookingService` - интерфейс автобронирования
- `INotificationService` - интерфейс уведомлений
- `IWBAPIClient` - интерфейс WB API клиента

### 2. Базовый класс (`base-service.ts`)
- Общая функциональность для всех сервисов
- Управление жизненным циклом
- Мониторинг и метрики
- Обработка ошибок и retry логика
- Логирование

### 3. Менеджер сервисов (`service-manager.ts`)
- Централизованное управление всеми сервисами
- Регистрация и получение сервисов
- Мониторинг здоровья системы
- Управление жизненным циклом

### 4. Унифицированные сервисы
- **UnifiedWBAPIClient** - единый клиент для WB API
- **UnifiedSlotSearchService** - поиск слотов
- **UnifiedAutoBookingService** - автобронирование
- **UnifiedNotificationService** - уведомления

## 🔄 Миграция

### Автоматическая миграция
```bash
# Запуск миграции
npm run app:migrate
```

### Что делает миграция
1. Удаляет дублирующиеся файлы
2. Обновляет импорты
3. Заменяет использование сервисов
4. Создает резервную копию

### Ручная миграция
Если автоматическая миграция не подходит, можно мигрировать вручную:

1. Замените импорты:
```typescript
// Было
import { SlotSearchService } from '@/lib/services/slot-search-service';

// Стало
import { getAppService } from '@/lib/app';
```

2. Замените создание сервисов:
```typescript
// Было
const service = new SlotSearchService();

// Стало
const service = getAppService('slotSearch');
```
