# Инструкция по использованию улучшенного скрипта автобронирования

## Основные изменения

### 1. Удалена авторизация
- Скрипт больше не содержит блок ввода телефона и SMS-кода
- Предполагается, что сессия уже сохранена в браузере

### 2. Динамический поиск поставки
- Номер поставки задается через `GlobalVariable.supplyNumber`
- Скрипт автоматически ищет поставку по номеру
- Проверяет наличие поставки в результатах поиска

### 3. Улучшенная обработка ошибок
- Добавлены try-catch блоки
- Подробное логирование всех операций
- Graceful handling при ошибках

### 4. Более стабильные операции
- Функции `safeClick()` и `safeSetText()` с повторными попытками
- Ожидания загрузки элементов
- Проверки успешности операций

## Настройка перед запуском

### 1. Сохранение сессии
Перед запуском скрипта необходимо:
1. Вручную авторизоваться в Wildberries Seller
2. Убедиться, что сессия сохранена (cookies, localStorage)
3. Проверить, что вы находитесь в нужном аккаунте

### 2. Настройка номера поставки
```groovy
GlobalVariable.supplyNumber = "445194"  // Замените на нужный номер
```

### 3. Обновление селекторов
Проверьте и обновите селекторы в Object Repository:
- `Page_/input__all-supplies-search` - поле поиска поставок
- `Page_/div__Table__td-content__OpbOC9lNW1` - найденная поставка
- `Page_/span__caption__kqFcIewCT5` - кнопка бронирования
- `Page_/button__button__Qmm2epbxz s__vFIVMtH33l` - кнопка подтверждения

## Логика работы

1. **Восстановление сессии**
   - Открывает браузер
   - Переходит на seller.wildberries.ru
   - Проверяет наличие авторизации

2. **Поиск поставки**
   - Переходит в раздел поставок
   - Вводит номер поставки в поиск
   - Проверяет наличие результатов

3. **Бронирование**
   - Выбирает найденную поставку
   - Открывает детали
   - Нажимает кнопку бронирования
   - Подтверждает действие

## Мониторинг и отладка

### Логи
Скрипт выводит подробные логи:
- `[INFO]` - информационные сообщения
- `[ERROR]` - ошибки и проблемы

### Обработка ошибок
- При критических ошибках скрипт останавливается
- Все ошибки логируются с временными метками
- Браузер закрывается в блоке `finally`
