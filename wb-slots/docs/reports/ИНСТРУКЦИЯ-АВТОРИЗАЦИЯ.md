# 🔐 Инструкция по авторизации Wildberries

## 🚀 Быстрый старт

### Автоматический режим (рекомендуется):
1. Откройте http://localhost:3003/wb-auth-debug
2. Нажмите **"Открыть браузер"**
3. Браузер автоматически откроется на странице поставок
4. Если потребуется авторизация - войдите в ЛК
5. Сессия сохранится автоматически

### Принудительное сохранение:
1. Если автоматическое сохранение не сработало
2. Нажмите **"Принудительно сохранить"**
3. Система принудительно сохранит все данные
4. Готово! Сессия сохранена для автобронирования

## 📋 Что происходит:

### ✅ Автоматический режим:
- Браузер открывается сразу на странице поставок
- Система автоматически переходит на `/supplies-management/all-supplies`
- Если нужна авторизация - пользователь входит в ЛК
- Автоматически сохраняет cookies, localStorage, sessionStorage
- Шифрует все данные для безопасности

### 🔧 Принудительное сохранение:
- Работает на любой странице Wildberries
- Автоматически переходит на страницу поставок
- Собирает все данные сессии
- Сохраняет в зашифрованном виде

### 🔒 Безопасность:
- Все данные шифруются AES-256
- Сессия истекает через 24 часа
- Данные хранятся в защищенной базе данных

### 📊 Отображение статуса:
- Показывает активность сессии
- Время последнего входа
- Время истечения
- ID сессии
- Готовность к автобронированию

## 🛠️ Решение проблем:

### Проблема: "Браузер не открывается на странице поставок"
**Решение:** 
1. Проверьте, что порт 3003 свободен
2. Перезапустите проект: `npm run dev -- -p 3003`
3. Очистите кэш браузера

### Проблема: "Сессия не сохраняется автоматически"
**Решение:** 
1. Нажмите кнопку **"Сохранить сессию"** в popup браузере
2. Система принудительно сохранит все данные
3. Проверьте логи в консоли браузера

### Проблема: "Ошибка при сохранении cookies"
**Решение:**
1. Убедитесь, что вы авторизованы в ЛК WB
2. Попробуйте перезайти в ЛК
3. Используйте принудительное сохранение

## 🎯 После авторизации:

1. Перейдите на http://localhost:3003/auto-booking
2. Убедитесь, что статус показывает "Сессия активна"
3. Создайте задачу автобронирования
4. Система будет использовать сохраненную сессию
