## 🏗️ Созданная архитектура

### Общая структура
```
src/lib/
├── architecture/           # Унифицированная архитектура
│   ├── unified-interfaces.ts      # Единые интерфейсы
│   ├── autobooking-interfaces.ts  # Интерфейсы автобронирования
│   ├── base-service.ts            # Базовый класс сервисов
│   ├── service-manager.ts         # Менеджер сервисов
│   └── index.ts                   # Экспорт архитектуры
├── services/               # Унифицированные сервисы
│   ├── unified-wb-api-client.ts        # WB API клиент
│   ├── unified-slot-search-service.ts  # Поиск слотов
│   ├── unified-auto-booking-service.ts # Автобронирование
│   ├── unified-notification-service.ts # Уведомления
│   ├── autobooking-manager.ts          # Менеджер автобронирования
│   ├── autobooking-entry-point.ts      # Точка входа автобронирования
│   ├── autobooking-integration.ts      # Интеграция автобронирования
│   └── index.ts                        # Экспорт сервисов
├── app.ts                  # Единая точка входа приложения
└── scripts/               # Скрипты управления
    ├── initialize-app.ts      # Инициализация приложения
    ├── migrate-to-unified.ts  # Миграция на новую архитектуру
    └── test-autobooking.ts    # Тестирование автобронирования
```

### API endpoints
- `GET /api/services?action=status` - статус всех сервисов
- `GET /api/services?action=health` - здоровье системы
- `GET /api/services?action=metrics` - метрики производительности
- `POST /api/services` - выполнение операций с сервисами
- `GET /api/autobooking?action=status` - статус автобронирования
- `GET /api/autobooking?action=health` - здоровье автобронирования
- `GET /api/autobooking?action=queue` - статус очереди
- `POST /api/autobooking` - операции автобронирования

## 🔄 Миграция

### Автоматическая миграция
```bash

npm run app:migrate
```

### Ручная миграция
1. Замените импорты:
```typescript
// Было
import { SlotSearchService } from '@/lib/services/slot-search-service';
import { AutoBookingService } from '@/lib/services/auto-booking-service';

// Стало
import { getAppService } from '@/lib/app';
```

2. Замените создание сервисов:
```typescript
// Было
const slotService = new SlotSearchService();
const bookingService = new AutoBookingService();

// Стало
const slotService = getAppService('slotSearch');
const bookingService = getAppService('autoBooking');
```
