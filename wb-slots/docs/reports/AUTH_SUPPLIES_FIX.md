# Исправление ошибки "Authentication required" при загрузке поставок

## Проблема
При попытке загрузить поставки в форме создания задачи возникает ошибка:
```
Error fetching supplies: "Authentication required"
```

## Причина
Пользователь не авторизован в системе или JWT токен не передается корректно.

## Решение

### 1. Диагностика проблемы
Запустите скрипт диагностики:
```bash
node debug-auth-supplies.js
```

### 2. Проверка конфигурации
Убедитесь, что созданы файлы конфигурации:
```bash
# Создание файлов .env
node setup-frontend-env.js
node setup-backend-env.js
```

### 3. Запуск сервисов
```bash
# Терминал 1: Frontend
npm run dev

# Терминал 2: Backend
cd backend && npm run start:dev
```

### 4. Авторизация в браузере
1. Откройте http://localhost:3000
2. Войдите в систему или зарегистрируйтесь
3. Перейдите к созданию задачи
4. Включите автобронирование
5. Проверьте загрузку поставок

## Устранение неполадок

### Если все еще ошибка 401:
1. **Очистите cookies браузера**
2. **Авторизуйтесь заново**
3. **Проверьте, что backend запущен**
4. **Проверьте файлы .env**

### Если backend не запускается:
1. Проверьте, что база данных запущена
2. Проверьте переменные в backend/.env
3. Установите зависимости: `cd backend && npm install`

### Если frontend не работает:
1. Проверьте переменные в .env.local
2. Перезапустите Next.js: `npm run dev`
3. Очистите кэш: `rm -rf .next`
