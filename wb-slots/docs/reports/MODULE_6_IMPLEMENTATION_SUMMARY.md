## 🔧 Ключевые особенности

### 1. Шифрование данных
- **Алгоритм**: AES-256-GCM с PBKDF2
- **Ключи**: 256-битные с 100,000 итераций PBKDF2
- **Соль**: Уникальная соль для каждого ключа
- **AAD**: Additional Authenticated Data для дополнительной защиты

### 2. Rate Limiting
- **Хранение**: Redis с автоматической очисткой
- **Стратегия**: Sliding window с экспоненциальным backoff
- **Конфигурации**:
  - WB API: 30 запросов/минуту
  - Telegram API: 20 запросов/минуту
  - Пользователи: 50 запросов/минуту
  - Задачи: 10 выполнений/5 минут

### 3. Обработка капчи
- **Типы**: reCAPTCHA, hCaptcha, обычная капча
- **Обнаружение**: По селекторам, тексту и URL
- **Уведомления**: Автоматические в Telegram
- **Ожидание**: До 10 минут на решение

### 4. Retry логика
- **Стратегии**: Простая, экспоненциальный backoff
- **Конфигурации**: Настраиваемые для разных операций
- **Ошибки**: Фильтрация по типам ошибок
- **Уведомления**: О повторных попытках и результатах
