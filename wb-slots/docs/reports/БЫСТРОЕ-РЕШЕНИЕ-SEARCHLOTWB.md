# 🚀 Быстрое решение для @SearchLotWB_bot

## ❌ Проблема
Нужно использовать существующего бота @SearchLotWB_bot для авторизации через Telegram.

## ✅ Решение (5 минут)

### 1. Получите токен бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/mybots`
3. Выберите @SearchLotWB_bot
4. Нажмите "API Token"
5. **Скопируйте токен**

### 2. Настройте токен в системе

**Вариант A: Через интерфейс (рекомендуется)**
1. Войдите с ролью `DEVELOPER` или `ADMIN`
2. Перейдите в `/settings/telegram`
3. Введите токен в секции "Настройки разработчика"
4. Нажмите "Обновить токен"

**Вариант B: Через скрипт**
```bash
node setup-searchlotwb-bot.js YOUR_BOT_TOKEN
```

### 3. Настройте Web App в BotFather

1. В BotFather отправьте `/newapp`
2. Выберите @SearchLotWB_bot
3. Введите название: `WB Slots Auth`
4. Введите описание: `Авторизация в системе`
5. **Введите URL**: `https://yourdomain.com/auth/telegram`
6. Нажмите "Готово"

### 4. Проверьте настройку

1. Откройте `/settings/telegram`
2. Увидите статус "Telegram бот настроен"
3. Нажмите "Авторизация" - откроется @SearchLotWB_bot
4. Проверьте Web App

## 🎉 Готово!

Теперь кнопка "Авторизация через Telegram" будет открывать @SearchLotWB_bot с настроенным Web App.

## 🆘 Если не работает

### Проблема: Токен не сохраняется
**Решение:**
1. Проверьте роль пользователя (DEVELOPER/ADMIN)
2. Проверьте формат токена
3. Проверьте логи приложения

### Проблема: Web App не открывается
**Решение:**
1. Проверьте URL в BotFather
2. Убедитесь что сайт доступен по HTTPS
3. Проверьте настройки Web App

### Проблема: Ошибка авторизации
**Решение:**
1. Проверьте токен в BotFather
2. Проверьте статус бота в системе
3. Проверьте логи приложения
