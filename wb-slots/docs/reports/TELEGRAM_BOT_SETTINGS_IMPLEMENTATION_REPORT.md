## 🏗️ Архитектура решения

### База данных
```
bot_settings
├── id (TEXT, PRIMARY KEY)
├── key (TEXT, UNIQUE) - ключ настройки
├── value (TEXT) - значение настройки
├── description (TEXT) - описание
├── is_encrypted (BOOLEAN) - флаг шифрования
├── created_at (TIMESTAMP)
└── updated_at (TIMESTAMP)
```

### Сервисы
```
BotSettingsService
├── getSetting(key) - получение настройки
├── setSetting(key, value) - сохранение настройки
├── getTelegramBotToken() - получение токена бота
├── setTelegramBotToken(token) - сохранение токена
└── isBotConfigured() - проверка настройки

TelegramService (обновлен)
├── initializeBotToken() - инициализация токена
├── updateBotToken(token) - обновление токена
├── isBotConfigured() - проверка настройки
└── sendNotification() - отправка уведомлений
```

### API Endpoints
```
GET /api/settings/telegram/admin
├── Возвращает настройки бота
├── Проверяет статус токена
└── Загружает шаблоны уведомлений

POST /api/settings/telegram/admin
├── action: "update_bot_token"
├── data: { botToken: "..." }
├── Валидация токена
└── Сохранение в БД
```

## 🚀 Инструкции по использованию

### Для разработчиков:

1. **Войдите в систему** с ролью `DEVELOPER` или `ADMIN`
2. **Перейдите в настройки** → Telegram → Настройки разработчика
3. **Введите токен бота** от @BotFather в поле "Новый Bot Token"
4. **Нажмите "Обновить токен"** - система проверит и сохранит токен
5. **Проверьте статус** - должен появиться зеленый индикатор "✅ Активен"

### Применение миграции:
```bash
cd wb-slots
node apply-bot-settings-migration.js
```
