# 🔐 Разделение проверки Токена API и WB Сессии

## 📋 Суть изменений

**Проблема:** Автобронирование ошибочно проверяло наличие токена API, хотя работает через браузерную сессию Playwright.

**Решение:** Разделена проверка на две независимые части:
1. **Токен API (SUPPLIES)** - для операций через API
2. **WB Сессия (браузер)** - для автобронирования через Playwright

---

## 🎯 Что требует Токен API

Токен API (категория `SUPPLIES`) **обязателен** для:

### 1. **Поиск слотов** 🔍
- API: `/api/tasks/search-slots`
- Метод: `WBSuppliesClient.searchAvailableSlots()`
- Код: `SlotSearchExecutor.searchSlotsWithConditions()`

### 2. **Получение складов** 🏭
- API: `/api/warehouses/sync`
- Метод: `WBSuppliesClient.getWarehouses()`
- Используется для синхронизации справочника складов

### 3. **Получение поставок** 📦
- API: `/api/supplies`
- Метод: `WBSuppliesClient.getSupplies()`
- Получение списка активных поставок для автобронирования

### ❌ Ошибки при отсутствии токена:
```
401 Unauthorized - токен истёк
403 Forbidden - нет прав доступа
```

---

## 🌐 Что требует WB Сессию (браузер)

WB Сессия (авторизация через браузер) **обязательна** для:

### 1. **Автобронирование слотов** ⚡
- Работает через Playwright (автоматизация браузера)
- Не использует API токен
- Требует активную сессию в браузере WB
- Проверка: `/api/wb-session/check`

### 2. **Что включает WB сессию:**
- Cookies авторизации WB
- Phone номер пользователя
- Активный статус (`isActive: true`)
- Свежесть сессии (не старше 7 дней)

## 🔧 Реализация

### **1. Новый API эндпоинт** 
`/api/wb-session/check` - проверка наличия активной WB сессии

```typescript
// Проверяет:
// 1. Есть ли активная WB сессия пользователя
// 2. Не истекла ли сессия (> 7 дней)

GET /api/wb-session/check

Response:
{
  success: true,
  data: {
    hasSession: true,
    sessionId: "...",
    phone: "+79001234567",
    lastActive: "2024-11-01T12:00:00Z",
    message: "Активная сессия Wildberries найдена"
  }
}
```

### **2. Обновлённый хук**
`useAutoBookingCheck()` - теперь проверяет WB сессию, а не токен

**Было:**
```typescript
// Проверял авторизацию в приложении
const session = useSessionCheck(60000);
return { canAutoBook: session.isActive };
```

**Стало:**
```typescript
// Проверяет WB сессию для Playwright
const checkWBSession = async () => {
  const response = await fetch('/api/wb-session/check');
  // Проверяет наличие активной браузерной сессии
};

return { canAutoBook: wbSessionStatus.hasSession };
```

### **3. Обновлённые сообщения в формах**

## 🧪 Как проверить

### **Тест 1: Автобронирование без токена API**
1. Удалите токен SUPPLIES в настройках
2. Авторизуйтесь через WB Auth (создайте WB сессию)
3. Создайте задачу с автобронированием ✅ Должно работать

### **Тест 2: Поиск слотов без токена API**
1. Удалите токен SUPPLIES
2. Попробуйте найти слоты ❌ Ошибка: "No active supplies token found"

### **Тест 3: Автобронирование без WB сессии**
1. Выйдите из WB (очистите WB сессию)
2. Попробуйте включить автобронирование ❌ Кнопка заблокирована с сообщением: "требуется WB сессия"

### **Тест 4: Все работает с токеном и сессией**
1. Добавьте токен SUPPLIES
2. Авторизуйтесь через WB Auth
3. Создайте задачу с поиском и автобронированием ✅ Все работает

## 💡 Инструкция для пользователей

### **Для поиска слотов:**
1. Перейдите в **Настройки** → **Токены API**
2. Добавьте токен категории **SUPPLIES**
3. Получить токен: https://seller.wildberries.ru/supplier-settings/access-to-api

### **Для автобронирования:**
1. Перейдите в **WB Auth**
2. Авторизуйтесь через Wildberries (введите телефон и код)
3. Система создаст браузерную сессию
4. Теперь можно использовать автобронирование

### **Для полного функционала:**
Нужны **оба**:
- ✅ Токен SUPPLIES (для API)
- ✅ WB Сессия (для автобронирования)
