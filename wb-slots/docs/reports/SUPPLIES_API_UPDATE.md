# Обновление API поставок Wildberries

## Изменения в формате запроса

API поставок Wildberries изменил формат запроса с GET на POST с телом запроса и новым заголовком авторизации.

### Старый формат (GET)
```bash
curl -X GET "https://supplies-api.wildberries.ru/api/v1/supplies?limit=100&offset=0" \
  -H "Authorization: Bearer YOUR_API_KEY_HERE"
```

### Новый формат (POST)
```bash
curl -X POST "https://supplies-api.wildberries.ru/api/v1/supplies?limit=100&offset=0" \
  -H "Authorization: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "statusIDs": [5, 6],
    "dates": [
      {
        "from": "2025-01-01",
        "till": "2025-01-31",
        "type": "factDate"
      }
    ]
  }'
```

## Внесенные изменения

### 1. Backend (NestJS)

#### `backend/src/lib/wb-client/base-client.ts`
- Изменен заголовок авторизации: `Authorization: ${token}`

#### `backend/src/lib/wb-client/supplies-client.ts`
- Метод `getSupplies()` изменен с GET на POST
- Добавлены параметры фильтрации:
  - `statusIDs: number[]` - массив ID статусов
  - `dateFrom?: string` - дата начала фильтрации
  - `dateTo?: string` - дата окончания фильтрации
- Добавлено тело запроса с фильтрами
- По умолчанию используются статусы черновик: `[5, 6]`

#### `backend/src/supplies/supplies.service.ts`
- Обновлена логика фильтрации поставок
- Статусы черновик: `statusIDs: [5, 6]`
- Убрана дополнительная фильтрация на стороне сервера

### 2. Frontend (Next.js)

#### `src/lib/wb-client/base-client.ts`
- Изменен заголовок авторизации: `Authorization: ${token}`

#### `src/lib/wb-client/supplies-client.ts`
- Метод `getSupplies()` обновлен аналогично backend
- Добавлена поддержка фильтрации по статусам и датам

## Статусы поставок

### Статусы черновик
- **ID 5** - Черновик (первый тип)
- **ID 6** - Черновик (второй тип)

### Другие статусы (примерные)
- **ID 1-4** - Активные статусы
- **ID 7+** - Завершенные статусы

## Параметры фильтрации

### Тело запроса
```json
{
  "statusIDs": [5, 6],           // Массив ID статусов для фильтрации
  "dates": [                     // Опциональный фильтр по датам
    {
      "from": "2025-01-01",      // Дата начала (ISO формат)
      "till": "2025-01-31",      // Дата окончания (ISO формат)
      "type": "factDate"         // Тип даты (factDate, supplyDate)
    }
  ]
}
```

### Query параметры
- `limit` - Количество поставок (по умолчанию 1000)
- `offset` - Смещение для пагинации (по умолчанию 0)

## Устранение неполадок

### Если поставки не загружаются:
1. Проверьте, что токен SUPPLIES активен
2. Убедитесь, что backend и frontend используют новый формат
3. Проверьте логи в консоли на наличие ошибок
4. Убедитесь, что статусы 5, 6 существуют в системе WB

### Если ошибка авторизации:
1. Проверьте формат токена (должен быть без префикса)
2. Убедитесь, что используется HeaderApiKey
3. Проверьте, что токен не истек
