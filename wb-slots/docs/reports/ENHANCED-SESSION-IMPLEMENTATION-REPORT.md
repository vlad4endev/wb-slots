## 🔐 Безопасность

### Шифрование:
- **Алгоритм:** AES-256-GCM
- **Ключ:** 32 байта (поддержка hex, base64, прямой формат)
- **IV:** 16 байт (генерируется случайно)
- **Auth Tag:** 16 байт

### Защита данных:
- Все данные сессии шифруются перед сохранением в БД
- Отпечатки целостности для проверки данных
- Защита от состояний гонки
- Валидация целостности при восстановлении
