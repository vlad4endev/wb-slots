# 🤖 Настройка Telegram Login Widget для @SearchLotWB_bot

## 🎯 Что это такое

Telegram Login Widget - это официальный способ авторизации через Telegram, который работает в любом браузере без необходимости открывать Telegram Web App.

## ✅ Преимущества

- ✅ **Работает в любом браузере** - не нужен Telegram
- ✅ **Официальный виджет** от Telegram
- ✅ **Простая настройка** - один скрипт
- ✅ **Безопасность** - проверка подписи
- ✅ **Красивый UI** - стандартная кнопка Telegram

## 🚀 Настройка

### Шаг 1: Настройка бота в BotFather

1. **Откройте [@BotFather](https://t.me/BotFather)** в Telegram
2. **Выберите бота** @SearchLotWB_bot
3. **Отправьте команду** `/setdomain`
4. **Введите домен** вашего сайта (например: `yourdomain.com`)
5. **Подтвердите** настройку

### Шаг 2: Настройка токена в системе

1. **Войдите в систему** с ролью `DEVELOPER` или `ADMIN`
2. **Перейдите в настройки** → `/settings/telegram`
3. **Введите токен** `7690700894:AAEGUGIqOeNcU30kG2bUrARxqht5qj058bI`
4. **Нажмите "Обновить токен"**
5. **Проверьте статус** - должен быть зеленый индикатор "Активен"

### Шаг 3: Тестирование

1. **Откройте страницу** `/auth/telegram-widget`
2. **Увидите кнопку** "Log in with Telegram"
3. **Нажмите кнопку** - откроется окно авторизации
4. **Авторизуйтесь** через Telegram
5. **Проверьте** что вы вошли в систему

## 🔧 Технические детали

### Компонент TelegramLoginWidget

```tsx
<TelegramLoginWidget 
  onAuth={handleTelegramAuth}
  onError={handleError}
  botName="SearchLotWB_bot"
  size="large"
  requestAccess="write"
/>
```

### API Endpoint

**POST** `/api/auth/telegram-widget`
- Обрабатывает данные от Telegram Login Widget
- Проверяет подпись данных
- Создает/обновляет пользователя
- Возвращает JWT токен

### Структура данных

```typescript
interface TelegramUser {
  id: number;
  first_name: string;
  last_name?: string;
  username?: string;
  photo_url?: string;
  auth_date: number;
  hash: string;
}
```

## 🚨 Важные моменты

### Настройка домена

- ✅ **Домен должен быть настроен** в BotFather
- ✅ **Домен должен быть HTTPS** в продакшене
- ✅ **Домен должен совпадать** с доменом сайта

### Проверка настройки

```bash
# Проверка токена
curl -X GET "http://localhost:3000/api/debug/telegram-token"
```

## 🔍 Отладка

### Проблема: Кнопка не появляется
**Решение:**
1. Проверьте настройку домена в BotFather
2. Проверьте токен бота в системе
3. Проверьте консоль браузера на ошибки

### Проблема: Ошибка авторизации
**Решение:**
1. Проверьте токен бота
2. Проверьте настройки домена
3. Проверьте логи сервера

### Проблема: Не работает в продакшене
**Решение:**
1. Убедитесь что домен настроен в BotFather
2. Убедитесь что сайт доступен по HTTPS
3. Проверьте настройки CORS
