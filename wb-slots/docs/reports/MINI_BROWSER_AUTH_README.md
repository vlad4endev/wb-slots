# 🔐 Система автоматической авторизации через мини-браузер

## 📋 Обзор

Новая система автоматически обнаруживает неавторизованные страницы и открывает мини-браузер для пользователя, чтобы он мог войти в систему. После успешной авторизации система обновляет сессию и продолжает процесс бронирования.

## 🚀 Как это работает

### 1. **Детекция неавторизации**
Система проверяет:
- Наличие ошибок 401 на странице
- Отсутствие элементов авторизованного пользователя
- Нахождение на страницах логина/авторизации

### 2. **Открытие мини-браузера**
При обнаружении неавторизации:
- Открывается новый браузер (не headless)
- Переход на `https://seller.wildberries.ru/login`
- Ожидание авторизации пользователя (до 5 минут)

### 3. **Обновление сессии**
После успешной авторизации:
- Извлечение всех куки из мини-браузера
- Получение токенов из localStorage/sessionStorage
- Обновление основного браузера
- Перезагрузка страницы с новой сессией

## ⚙️ Настройки

### Таймауты
- **Максимальное время ожидания**: 5 минут (150 попыток по 2 секунды)
- **Таймаут загрузки страницы**: 30 секунд
- **Задержка между проверками**: 2 секунды

### Браузер авторизации
- **Режим**: Не headless (видимый пользователю)
- **Размер окна**: 1200x800
- **Антидетект**: Включен

## 🔧 Устранение неполадок

### Проблема: Браузер не открывается
**Решение**: Проверьте установку Puppeteer и Chrome
```bash
npm install puppeteer
```

### Проблема: Авторизация не завершается
**Решение**: 
- Убедитесь, что пользователь завершил вход в систему
- Проверьте, что вы не на странице логина
- Увеличьте таймаут в коде

### Проблема: Сессия не обновляется
**Решение**:
- Проверьте, что куки извлекаются корректно
- Убедитесь, что localStorage/sessionStorage доступны
- Проверьте права доступа к домену

## 🚨 Важные замечания

1. **Безопасность**: Мини-браузер закрывается после авторизации
2. **Производительность**: Дополнительный браузер использует ресурсы
3. **Таймауты**: Система ждет максимум 5 минут
4. **Зависимости**: Требует установленный Chrome/Chromium

## 🔄 Алгоритм работы

```
1. Проверка аутентификации
   ├── ✅ Авторизован → Продолжить бронирование
   └── ❌ Не авторизован → Шаг 2

2. Открытие мини-браузера
   ├── Запуск нового браузера
   ├── Переход на страницу логина
   └── Ожидание авторизации пользователя

3. Извлечение данных
   ├── Получение куки
   ├── Получение токенов
   └── Закрытие мини-браузера

4. Обновление сессии
   ├── Установка куки в основной браузер
   ├── Обновление localStorage/sessionStorage
   └── Перезагрузка страницы

5. Финальная проверка
   ├── Проверка аутентификации
   └── Продолжение бронирования
```
