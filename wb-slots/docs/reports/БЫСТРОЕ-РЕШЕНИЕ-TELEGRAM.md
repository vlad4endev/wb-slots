# 🚀 Быстрое решение проблемы с Telegram авторизацией

## ❌ Проблема
При нажатии "Авторизация через Telegram" открывается непонятный канал.

## ✅ Быстрое решение

### 1. Создайте бота (2 минуты)

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Введите имя: `WB Slots Bot`
4. Введите username: `wb_slots_your_bot` (замените на свой)
5. **СОХРАНИТЕ ТОКЕН** который даст BotFather

### 2. Настройте Web App (1 минута)

1. В BotFather отправьте `/newapp`
2. Выберите вашего бота
3. Введите название: `WB Slots App`
4. Введите описание: `Авторизация в системе`
5. **Введите URL**: `https://yourdomain.com/auth/telegram`
6. Нажмите "Готово"

### 3. Добавьте в .env файл

```env
TELEGRAM_BOT_TOKEN="ваш_токен_от_BotFather"
NEXT_PUBLIC_TELEGRAM_BOT_USERNAME="wb_slots_your_bot"
```

### 4. Перезапустите приложение

```bash
npm run dev
# или
yarn dev
```

## 🎉 Готово!

Теперь кнопка "Авторизация через Telegram" будет открывать ваш бот с кнопкой Web App.

## 🔍 Проверка

1. Откройте `/settings/telegram`
2. Увидите статус "Telegram бот настроен"
3. Нажмите "Авторизация" - откроется ваш бот

## 🆘 Если не работает

1. **Проверьте username** - должен быть без @
2. **Проверьте URL** - должен быть HTTPS
3. **Проверьте токен** - должен быть от BotFather
4. **Перезапустите** приложение
