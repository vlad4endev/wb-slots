## 🔐 Разделение Токена и Сессии

### **Важное изменение!**

Теперь система различает:

| Что проверяется | Для чего | API |
|----------------|----------|-----|
| **Токен API (SUPPLIES)** | Поиск слотов, склады, поставки | `/api/auth/me` |
| **WB Сессия (браузер)** | Автобронирование через Playwright | `/api/wb-session/check` |

### **До изменений:**
```typescript
// Автобронирование проверяло общую сессию приложения
const { canAutoBook } = useAutoBookingCheck();
// canAutoBook зависело от /api/auth/me
```

### **После изменений:**
```typescript
// Автобронирование проверяет WB сессию
const { canAutoBook } = useAutoBookingCheck();
// canAutoBook зависит от /api/wb-session/check
// Проверяет наличие активной браузерной сессии WB
```

### **Результат:**
- ✅ Можно использовать автобронирование **БЕЗ** токена API
- ✅ Можно использовать поиск **БЕЗ** WB сессии
- ✅ Правильное разделение зон ответственности

## 🐛 Исправленные ошибки

### **1. Ошибка 401 Unauthorized**

#### Было:
```
❌ Ошибка при поиске слотов: Error [WBClientError]: Request failed with status code 401
No notification channels configured for user
```

#### Стало:
```
❌ Поиск остановлен: 🔐 Токен Wildberries истёк или недействителен

📋 Что делать:
1. Перейдите в настройки → Токены API
2. Обновите или добавьте новый токен категории SUPPLIES
3. Получить токен: https://seller.wildberries.ru/supplier-settings/access-to-api

⚠️ Детали ошибки:
   • HTTP статус: 401
   • Код ошибки WB: ...
   • Сообщение: Request failed with status code 401

💡 После обновления токена создайте новую задачу или перезапустите текущую.
```

#### Что улучшено:
- ✅ Задача автоматически останавливается
- ✅ Статус меняется на `FAILED`
- ✅ Задача отключается (`enabled = false`)
- ✅ Детальные инструкции в логах
- ✅ Попытка отправить уведомление
- ✅ Graceful handling если уведомления не настроены

### **2. Ошибка 403 Forbidden**

## ✨ Новые возможности

### **1. Готовые периоды дат**
Вместо ручного выбора - одна кнопка:
- 📅 **На сегодня** - поиск только на текущий день
- 🌅 **На завтра** - поиск на завтрашний день
- 📆 **На 3 дня** - с сегодня по послезавтра
- 📅 **На неделю** - с сегодня на 7 дней вперёд
- 📋 **На 2 недели** - с сегодня на 14 дней
- 📆 **На месяц** - с сегодня на 30 дней

### **2. Ручной ввод номера поставки**
Два режима:
- **Выбор из списка** - показывает активные поставки
- **Ручной ввод** - просто вводите номер

### **3. Валидация формы**
Проверяет всё:
- Название (обязательно, макс 100 символов)
- Склады (минимум 1)
- Типы поставки (минимум 1)
- Коэффициенты (-10 до 50, мин < макс)
- Даты (начало < конца, не в прошлом, макс 90 дней)
- Номер поставки (если автобронирование)
- Политика повторов (0-10, 1-60 сек)

### **4. Сохранение настроек**
- Автосохранение при создании задачи
- Автозагрузка при открытии формы
- Хранение 30 дней
- Сохраняет: фильтры, политику повторов, приоритет

### **5. Информативные сообщения**
Вместо технических ошибок - понятные инструкции:
- Что произошло
- Почему это произошло
- Что нужно сделать
- Куда перейти
- Прямые ссылки
