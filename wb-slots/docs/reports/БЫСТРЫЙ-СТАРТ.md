## 🎯 Как использовать:

### 1. Откройте отладочную страницу:
```
http://localhost:3003/wb-auth-debug
```

### 2. Нажмите "Открыть браузер"
- Браузер откроется на странице поставок WB
- Если нужна авторизация - войдите в ЛК

### 3. Сессия сохранится автоматически
- Система соберет все cookies и данные
- Сохранит в зашифрованном виде
- Закроет браузер

### 4. Если автоматическое сохранение не сработало:
- Нажмите "Принудительно сохранить"
- Система принудительно сохранит данные
