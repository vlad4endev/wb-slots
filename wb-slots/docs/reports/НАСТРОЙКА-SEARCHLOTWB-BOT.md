# 🤖 Настройка @SearchLotWB_bot для авторизации

## 🎯 Задача
Настроить существующего бота @SearchLotWB_bot для авторизации через Telegram Web App.

## ✅ Пошаговая настройка

### Шаг 1: Получение токена бота

1. **Откройте [@BotFather](https://t.me/BotFather)** в Telegram
2. **Отправьте команду** `/mybots`
3. **Выберите бота** @SearchLotWB_bot
4. **Нажмите "API Token"**
5. **Скопируйте токен** (формат: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Настройка токена в системе

1. **Войдите в систему** с ролью `DEVELOPER` или `ADMIN`
2. **Перейдите в настройки** → `/settings/telegram`
3. **Найдите секцию "Настройки разработчика"**
4. **Введите токен** от @SearchLotWB_bot
5. **Нажмите "Обновить токен"**
6. **Проверьте статус** - должен быть зеленый индикатор "Активен"

### Шаг 3: Настройка Web App в BotFather

1. **В BotFather** выберите @SearchLotWB_bot
2. **Отправьте команду** `/newapp`
3. **Выберите бота** @SearchLotWB_bot
4. **Введите название**: `WB Slots Auth`
5. **Введите описание**: `Авторизация в системе WB Slots`
6. **Загрузите иконку** (опционально)
7. **Введите URL Web App**: `https://yourdomain.com/auth/telegram`
8. **Нажмите "Готово"**

### Шаг 4: Проверка настройки

1. **Откройте страницу** `/settings/telegram`
2. **Проверьте статус** - должно быть "Telegram бот настроен"
3. **Нажмите "Авторизация"** - должен открыться @SearchLotWB_bot
4. **Проверьте Web App** - должна быть кнопка для открытия приложения

## 🔧 Альтернативная настройка через API

Если у вас есть доступ к базе данных, можно настроить токен напрямую:

```sql
-- Вставка токена в таблицу bot_settings
INSERT INTO bot_settings (id, key, value, description, is_encrypted, created_at, updated_at)
VALUES (
  'telegram_bot_token_' || extract(epoch from now())::text,
  'telegram_bot_token',
  'YOUR_BOT_TOKEN_HERE',
  'Telegram bot token for @SearchLotWB_bot',
  true,
  now(),
  now()
);
```
