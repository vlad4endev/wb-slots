## 🔧 Техническая архитектура

### Структура тестов
```
src/__tests__/
├── unit/                    # Unit тесты
│   ├── edge-cases.test.ts   # Edge cases
│   ├── *.test.ts           # Обычные unit тесты
├── integration/             # Интеграционные тесты
│   ├── complex-workflows.test.ts
│   └── *.test.ts
├── performance/             # Тесты производительности
├── mocks/                   # Моки
│   └── comprehensive-mocks.ts
└── setup/                   # Настройка
    ├── jest.setup.js
    └── custom-matchers.js

tests/e2e/                   # E2E тесты
├── complex-flows.spec.ts
├── auth.spec.ts
└── tasks.spec.ts
```

### Конфигурация
- **Jest**: `jest.config.js` - конфигурация unit/integration тестов
- **Playwright**: `playwright.config.ts` - конфигурация E2E тестов
- **Vitest**: `vitest.config.ts` - конфигурация быстрых тестов
