### 🚨 ПРОБЛЕМА #1: Неправильная структура блоков try-catch

**Местонахождение:** `src/lib/services/auto-booking-service.ts`, строки 315-494

**Текущий код (НЕПРАВИЛЬНО):**
```typescript
try {
  while (attempt < retryConfig.maxAttempts) {
    attempt++;
    
    try {  // ← Внутренний try (строка 320)
      // Step 1: Initialize browser
      const { browser, context, page } = await this.initializeBrowser(timeoutConfig);
      
      browserResources.browser = browser;
      browserResources.context = context;
      browserResources.page = page;
      
      stepResults.push(await this.recordStep('browser_init', true, 0));

    // ❌ ОШИБКА: Код ВНЕ блока try!
    const stopPeriodicScreenshots = await this.monitor.startPeriodicScreenshots(page, 15000);
    // ↑ page может быть undefined если initializeBrowser упал!
    
    const sessionResult = await this.validateAndRestoreSession(page, config.userId);
    // ↑ page undefined!
    
    // ... остальной код использует page
    
    } finally {
      await this.cleanupBrowserResources(browserResources, attempt);
    }
  }
}
```

**Проблема:**
- Блок `try` начинается на строке 320
- Но закрывается СРАЗУ после `recordStep` (строка 334)
- Весь остальной код (336-378) находится **ВНЕ** блока try
- Если `initializeBrowser()` упадёт → `page` = undefined
- Но код продолжает работать и пытается использовать `page` → **ОШИБКА!**

**Правильная структура:**
```typescript
try {
  while (attempt < retryConfig.maxAttempts) {
    attempt++;
    
    // Объявляем переменные ДО блока
    let stopPeriodicScreenshots: (() => void) | null = null;
    
    try {  // ← Весь код должен быть ВНУТРИ
      // Step 1: Initialize browser
      const { browser, context, page } = await this.initializeBrowser(timeoutConfig);
      
      browserResources.browser = browser;
      browserResources.context = context;
      browserResources.page = page;
      
      stepResults.push(await this.recordStep('browser_init', true, 0));
      
      // ✅ Код ВНУТРИ try
      stopPeriodicScreenshots = await this.monitor.startPeriodicScreenshots(page, 15000);
      
      const sessionResult = await this.validateAndRestoreSession(page, config.userId);
      
      // ... весь остальной код
      
    } catch (error) {
      // Обработка ошибок
    } finally {
      // Остановка скриншотов
      if (stopPeriodicScreenshots) {
        stopPeriodicScreenshots();
      }
      
      await this.cleanupBrowserResources(browserResources, attempt);
    }
  }
}
```

### 🚨 ПРОБЛЕМА #2: a.evaluate is not a function

**Причина:** Вызов `page.evaluate()` когда page = null/undefined/closed

**Места возникновения:**
1. `this.monitor.startPeriodicScreenshots(page, 15000)` - если page undefined
2. `this.sessionManager.checkAuthenticationStatus(page)` - если page closed
3. `await page.evaluate()` в любых методах после ошибки

**Исправление:**
```typescript
// В начале КАЖДОГО метода, использующего page:
if (!page || page.isClosed()) {
  throw new Error('Page is not available or closed');
}

// ИЛИ используем optional chaining:
const result = await page?.evaluate(...);
if (!result) {
  throw new Error('Page evaluation failed');
}
```

### 🚨 ПРОБЛЕМА #4: Сессия не восстанавливается (cookies не применяются)

**Местонахождение:** `validateAndRestoreSession()`, строки 716-760

**Проблема:**
```typescript
const sessionResult = await this.sessionManager.restoreSession(userId, page.context());
// ↑ Возвращает { isValid: true }, но cookies НЕ применяются к page!
```

**Причина:**
`sessionManager.restoreSession()` декодирует cookies из БД, но **НЕ применяет их к browser context**.

**Что происходит:**
1. `restoreSession()` читает sessionData из БД
2. Декодирует cookies
3. Возвращает `{ isValid: true, metadata: { cookies } }`
4. **НО:** Cookies остаются в памяти, не применяются к браузеру!
5. Браузер работает БЕЗ cookies → редирект на логин

**Исправление:**
```typescript
// ПОСЛЕ успешного restoreSession:
const sessionResult = await this.sessionManager.restoreSession(userId, page.context());

if (sessionResult.isValid && sessionResult.metadata?.cookies) {
  // ✅ КРИТИЧНО: Применяем cookies к browser context!
  try {
    await page.context().addCookies(sessionResult.metadata.cookies);
    this.logger.info('✅ Cookies restored to browser', {
      count: sessionResult.metadata.cookies.length
    });
  } catch (cookieError) {
    this.logger.warn('Failed to apply cookies', { error: cookieError });
  }
  
  // ✅ Применяем localStorage
  if (sessionResult.metadata?.localStorage) {
    await page.evaluate((storage) => {
      for (const [key, value] of Object.entries(storage)) {
        localStorage.setItem(key, value);
      }
    }, sessionResult.metadata.localStorage);
  }
}
```

### 🚨 ПРОБЛЕМА #6: Нет централизованной обработки ошибок

**Проблема:**
- Множество `try/catch` блоков
- Каждый обрабатывает ошибки по-своему
- Нет единого формата логирования
- Некоторые ошибки проглатываются

**Исправление:**
```typescript
class EnhancedErrorHandler {
  static async handleBookingError(
    error: any,
    context: {
      step: string;
      userId: string;
      taskId: string;
      page?: Page;
    }
  ): Promise<EnhancedBookingError> {
    // 1. Логирование
    logger.error(`Error in ${context.step}`, {
      error: error.message,
      stack: error.stack,
      ...context
    });
    
    // 2. Screenshot
    if (context.page && !context.page.isClosed()) {
      try {
        await context.page.screenshot({
          path: `screenshots/error-${context.step}-${Date.now()}.png`
        });
      } catch (screenshotError) {
        logger.warn('Failed to take error screenshot');
      }
    }
    
    // 3. Классификация ошибки
    const enhancedError = this.classifyError(error);
    
    // 4. Уведомление
    await this.notifyError(enhancedError, context);
    
    return enhancedError;
  }
  
  static classifyError(error: any): EnhancedBookingError {
    const message = error?.message || 'Unknown error';
    
    if (message.includes('timeout')) {
      return new EnhancedBookingError(message, 'TIMEOUT_ERROR', true, error);
    }
    
    if (message.includes('login') || message.includes('unauthorized')) {
      return new SessionExpiredError(message, error);
    }
    
    // ... и т.д.
    
    return new EnhancedBookingError(message, 'UNKNOWN_ERROR', false, error);
  }
}

// Использование:
try {
  // ... код бронирования
} catch (error) {
  const enhancedError = await EnhancedErrorHandler.handleBookingError(error, {
    step: 'session_validation',
    userId,
    taskId,
    page
  });
  
  throw enhancedError;
}
```
