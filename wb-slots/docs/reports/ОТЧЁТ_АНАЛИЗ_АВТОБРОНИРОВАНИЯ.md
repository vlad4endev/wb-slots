## 🚨 КРИТИЧНЫЕ ПРОБЛЕМЫ (требуют немедленного исправления)

### #1: Структура try-catch НАРУШЕНА

**Файл:** `src/lib/services/auto-booking-service.ts`  
**Строки:** 315-494

**Проблема:**
```typescript
try {
  const { page } = await this.initializeBrowser(timeoutConfig);
  // ...
} // ← try ЗАКРЫВАЕТСЯ ЗДЕСЬ (строка 334)

// ❌ ОШИБКА: Весь код ниже ВНЕ блока try!
const stopPeriodicScreenshots = await this.monitor.startPeriodicScreenshots(page, 15000);
// ↑ page может быть undefined!

const sessionResult = await this.validateAndRestoreSession(page, config.userId);
// ↑ page undefined → ОШИБКА!
```

**Влияние:** 
- 🔴 Если `initializeBrowser()` упадёт → `page` = undefined
- 🔴 Но код продолжает выполняться
- 🔴 Все вызовы `page.xxx()` падают с ошибкой
- 🔴 Браузер не закрывается (утечка памяти)

## 🛠️ ЧТО НУЖНО ИСПРАВИТЬ

### Фаза 1: Критичные (СЕЙЧАС)

**1. Исправить структуру try-catch:**
```typescript
// ДО:
try {
  const { page } = await initBrowser();
} // ← ОШИБКА: закрывается рано!

const result = await doSomething(page); // page undefined!

// ПОСЛЕ:
try {
  const { page } = await initBrowser();
  
  const result = await doSomething(page); // ✅ page доступна
  
} catch (error) {
  // обработка
} finally {
  // cleanup
}
```

**2. Применить cookies к браузеру:**
```typescript
const sessionResult = await this.sessionManager.restoreSession(userId, page.context());

if (sessionResult.isValid && sessionResult.metadata?.cookies) {
  // ✅ ПРИМЕНЯЕМ cookies!
  await page.context().addCookies(sessionResult.metadata.cookies);
  
  // ✅ ПРИМЕНЯЕМ localStorage!
  await page.evaluate((storage) => {
    for (const [key, value] of Object.entries(storage)) {
      localStorage.setItem(key, value);
    }
  }, sessionResult.metadata.localStorage);
}
```

**3. Объявить переменные ДО try:**
```typescript
let stopPeriodicScreenshots: (() => void) | null = null;

try {
  const { page } = await initBrowser();
  
  stopPeriodicScreenshots = await this.monitor.startPeriodicScreenshots(page, 15000);
  
  // ... код ...
  
} finally {
  if (stopPeriodicScreenshots) {
    stopPeriodicScreenshots();
  }
}
```
