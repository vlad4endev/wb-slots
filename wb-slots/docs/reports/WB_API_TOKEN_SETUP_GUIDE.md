# Руководство по настройке API ключа Wildberries

## Проблема
Система использует fallback данные (20 складов) вместо получения всех складов из API WB, потому что:
- ❌ API ключ WB не найден в настройках
- ❌ Домен `suppliers-api.wildberries.ru` недоступен (требует правильной авторизации)

## Решение

### 1. Получение API ключа WB

1. **Войдите в личный кабинет Wildberries**:
   - Перейдите на [seller.wildberries.ru](https://seller.wildberries.ru)
   - Войдите в свой аккаунт продавца

2. **Перейдите в настройки API**:
   - В личном кабинете найдите раздел "Настройки" или "API"
   - Найдите раздел "API ключи" или "Токены доступа"

3. **Создайте новый API ключ**:
   - Нажмите "Создать новый ключ" или "Добавить токен"
   - Выберите права доступа для получения информации о складах
   - Скопируйте созданный API ключ

### 2. Добавление API ключа в систему

1. **Перейдите в настройки токенов**:
   - В приложении WB Slots перейдите в "Настройки" → "Токены"
   - Или используйте прямой URL: `/settings`

2. **Добавьте новый токен**:
   - Нажмите "Добавить токен"
   - **Категория**: выберите `MARKETPLACE`
   - **Токен**: вставьте скопированный API ключ WB
   - Нажмите "Сохранить"

### 3. Проверка настройки

1. **Проверьте токены**:
   - Перейдите на `/api/debug/user-tokens`
   - Убедитесь, что есть токен с категорией `MARKETPLACE`

2. **Повторите синхронизацию складов**:
   - Перейдите в "Настройки складов"
   - Нажмите "Обновить справочник складов"
   - Система должна получить все доступные склады (до 110)

## Ожидаемый результат

После добавления API ключа в логах должно появиться:
```
🔍 Ищем токен MARKETPLACE для пользователя: [user_id]
🔑 Найден и расшифрован токен MARKETPLACE для WB API
📅 Токен создан: [дата]
🔄 API попытка 1/1: https://suppliers-api.wildberries.ru/api/v1/warehouses
📡 API ответ: 200 OK
✅ Получены данные от API: [количество] складов
```

## Альтернативные решения

### Если API ключ не работает:
1. **Проверьте права доступа** - убедитесь, что ключ имеет права на получение информации о складах
2. **Обновите ключ** - возможно, ключ истек или был отозван
3. **Обратитесь в поддержку WB** - если проблема с API endpoints

### Если домен недоступен:
1. **Проверьте интернет-соединение**
2. **Попробуйте с VPN** - возможно, есть региональные ограничения
3. **Обратитесь в поддержку WB** - возможно, изменились API endpoints

## Текущий статус

- ✅ **Система работает**: Использует fallback данные (20 складов)
- ⚠️ **API недоступен**: Нужен токен для получения всех складов
- 🔧 **Требуется настройка**: Добавьте API ключ WB с категорией `MARKETPLACE`

## Поддержка

Если у вас возникли проблемы:
1. Проверьте логи в консоли браузера
2. Используйте debug endpoint `/api/debug/user-tokens`
3. Обратитесь к документации WB API
4. Свяжитесь с технической поддержкой
