# 📱 Настройка Telegram уведомлений

## Проблема
Вы видите ошибку: `No notification channels configured for user`

Это означает, что в системе не настроены уведомления Telegram для вашего пользователя.

## 🚀 Быстрая настройка (через скрипт)

### Шаг 1: Получите свой Telegram Chat ID

**Вариант 1 (Рекомендуется): Через интерфейс**
1. Откройте http://localhost:3000/settings
2. Перейдите в раздел "Уведомления"
3. Нажмите кнопку **"Получить ID"** рядом с полем Chat ID
4. Откроется бот [@chatIDrobot](https://t.me/chatIDrobot) в Telegram
5. Нажмите START или отправьте любое сообщение боту
6. Бот отправит вам ваш Chat ID
7. Скопируйте число и вставьте в поле Chat ID
8. Нажмите "Сохранить" - Chat ID сохранится в базу данных

**Вариант 2: Вручную через Telegram**
1. Откройте Telegram
2. Найдите бота [@chatIDrobot](https://t.me/chatIDrobot) или `@userinfobot`
3. Напишите ему `/start`
4. Бот отправит вам информацию, включая **Chat ID** (число, например: `123456789`)

### Шаг 2: Запустите скрипт настройки

```bash
cd wb-slots
node setup-telegram-notifications.js <ВАШ_USER_ID> <ВАШ_CHAT_ID>
```

**Пример:**
```bash
node setup-telegram-notifications.js cmgpoehb80000y43eopvxe7fa 123456789
```

Где:
- `cmgpoehb80000y43eopvxe7fa` - ваш User ID из системы
- `123456789` - ваш Chat ID из Telegram

### Шаг 3: Проверка

После запуска скрипта вы увидите:
```
✅ Настройки Telegram успешно сохранены!
🎉 Настройки корректны! Уведомления будут работать.
```

### Шаг 4: Запустите бота

1. Найдите вашего Telegram бота (по токену, который вы настроили в `TELEGRAM_BOT_TOKEN`)
2. Напишите ему `/start`
3. Теперь бот может отправлять вам уведомления!

## 🌐 Настройка через интерфейс (Рекомендуется)

### Пошаговая инструкция:

1. **Откройте настройки**
   - Перейдите: http://localhost:3000/settings
   - Откройте вкладку **"Уведомления"**

2. **Получите Chat ID**
   - Нажмите кнопку **"Получить ID"** рядом с полем Chat ID
   - Откроется [@chatIDrobot](https://t.me/chatIDrobot) в новой вкладке
   - В Telegram нажмите START
   - Бот отправит вам ваш Chat ID (число)

3. **Сохраните настройки**
   - Скопируйте Chat ID из Telegram
   - Вставьте в поле "Chat ID"
   - Включите галочку "Получать уведомления о найденных слотах"
   - Нажмите **"Сохранить настройки"**

4. **Готово!** ✅
   - Chat ID автоматически сохранится в базе данных
   - При следующем визите настройки загрузятся автоматически
   - Менять Chat ID нужно только если сменился аккаунт Telegram

### Вариант 2: Через API

```bash
curl -X POST http://localhost:3000/api/settings/telegram/user \
  -H "Content-Type: application/json" \
  -d '{
    "chatId": "123456789",
    "enabled": true
  }'
```

## ❓ Часто задаваемые вопросы

### Где найти Bot Token?

**⚠️ ВАЖНО:** Bot Token - это **системная настройка**, которую устанавливает только администратор/разработчик приложения.

**Обычные пользователи НЕ МОГУТ менять токен бота!**

**Для администратора:**

Bot Token настраивается одним из способов:

1. **Через переменную окружения** (рекомендуется):
   ```bash
   # В файле .env
   TELEGRAM_BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
   ```

2. **Через настройки в базе данных**:
   - Только для администраторов
   - Через раздел "Настройки разработчика" в интерфейсе

**Как создать бота (для администратора):**
1. Откройте Telegram
2. Найдите `@BotFather`
3. Отправьте `/newbot`
4. Следуйте инструкциям
5. Получите токен (формат: `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`)
6. Установите токен через .env файл или настройки в админ-панели

**Один бот - все пользователи:**
- Токен бота распространяется на ВСЕХ пользователей системы
- Все пользователи получают уведомления от одного бота
- Каждый пользователь настраивает только свой Chat ID

### Как узнать свой User ID в системе?

User ID выводится в консоли при запуске задачи. Пример из вашего лога:
```
📱 Getting Telegram notification status for user cmgpoehb80000y43eopvxe7fa
```

Здесь `cmgpoehb80000y43eopvxe7fa` - это User ID.

Или через API:
```bash
# Получить текущего пользователя
curl http://localhost:3000/api/auth/me
```

### Уведомления всё равно не приходят

1. **Проверьте, что бот запущен**: Напишите боту `/start`
2. **Проверьте настройки**: `node check-user-telegram-settings.js <USER_ID>`
3. **Проверьте токен бота**: Убедитесь что `TELEGRAM_BOT_TOKEN` корректный
4. **Проверьте логи**: Ищите сообщения вида:
   - `✅ Telegram notification sent to user`
   - или `⚠️ Failed to send telegram notification`

## 🛠️ Troubleshooting

### Ошибка: "Telegram bot token not configured"

Установите токен бота:
```bash
# В .env файле
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

Или через базу данных (таблица `bot_settings`).

### Ошибка: "Chat not found"

Это означает, что бот не может отправить сообщение. Решение:
1. Найдите бота в Telegram по username (смотрите в @BotFather)
2. Напишите боту `/start`
3. После этого бот сможет отправлять вам сообщения
