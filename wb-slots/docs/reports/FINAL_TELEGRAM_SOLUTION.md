# 🎯 Финальное решение проблемы "Bot token not configured"

## 🚨 Проблема
```
POST /api/settings/telegram/admin 400 in 51ms
User authenticated successfully: { id: 'cmfvmlf4x0000pmjsmd3eouhu', email: 'vl4en.95@yandex.ru' }
```

## 🔍 Диагностика показала:

### ✅ Что работает:
- **Пользователь аутентифицирован** ✅
- **Роль DEVELOPER установлена** ✅  
- **База данных в порядке** ✅
- **API endpoints существуют** ✅

### ❌ Проблема:
- **Скрипты не передают cookies** для аутентификации
- **API требует аутентификации** через cookies
- **Ошибка 401 Unauthorized** интерпретируется как 400

## ✅ Решение: Настройка через .env.local

### Шаг 1: Создание Telegram бота

1. **Откройте Telegram** и найдите [@BotFather](https://t.me/botfather)
2. **Отправьте команду:** `/newbot`
3. **Введите имя бота:** `WB Slots Notifier`
4. **Введите username:** `wb_slots_notifier_bot` (уникальный)
5. **Скопируйте токен** (формат: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Настройка токена

**Запустите скрипт настройки:**
```bash
node setup-telegram-env.js
```

**Вставьте токен** из шага 1.

### Шаг 3: Перезапуск сервера

```bash
# Остановите текущий сервер (Ctrl+C)
# Затем запустите заново:
npm run dev
```

### Шаг 4: Проверка результата

```bash
node check-telegram-token.js
```

**Ожидаемый результат:**
```
✅ Telegram bot token is configured!
```

## 🚀 Альтернативное решение: Через браузер

Если скрипт не работает:

1. **Откройте браузер:** http://localhost:3000
2. **Войдите в систему** (если не авторизованы)
3. **Перейдите на:** http://localhost:3000/settings/telegram
4. **В разделе "Настройки разработчика":**
   - Вставьте токен бота
   - Нажмите "Сохранить токен"

## 🧪 Проверка работы

### После настройки токена:

1. **Откройте:** http://localhost:3000/settings/telegram
2. **Проверьте статус бота** - должен быть зеленый "настроен"
3. **Попробуйте отправить тестовое сообщение**

### Ожидаемые результаты:
- ✅ Ошибка 400 исчезнет
- ✅ Статус бота: "настроен" (зеленый)
