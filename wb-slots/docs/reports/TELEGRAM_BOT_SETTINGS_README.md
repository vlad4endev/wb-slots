# 🤖 Настройки Telegram бота

## 📋 Обзор

Добавлена возможность настройки токена Telegram бота через веб-интерфейс. Теперь разработчики могут легко добавлять и обновлять токен бота без необходимости редактирования файлов конфигурации.

## ✨ Новые возможности

### 🔧 Админские настройки
- **Поле для ввода токена бота** - безопасное поле с типом `password`
- **Валидация токена** - автоматическая проверка токена через Telegram API
- **Сохранение в базе данных** - токен сохраняется в таблице `bot_settings`
- **Отображение статуса бота** - показывает информацию о текущем боте

### 🗄️ База данных
- **Новая таблица `bot_settings`** - для хранения настроек бота
- **Шифрование токенов** - токены помечаются как зашифрованные
- **Уникальные ключи** - каждый тип настройки имеет уникальный ключ

### 🔄 API обновления
- **Обновлен `/api/settings/telegram/admin`** - добавлена поддержка сохранения токена
- **Новый сервис `BotSettingsService`** - для работы с настройками бота
- **Обновлен `TelegramService`** - теперь использует токен из базы данных

## 📖 Использование

### Для разработчиков

1. **Войдите в систему** с ролью `DEVELOPER` или `ADMIN`
2. **Перейдите в настройки** → Telegram → Настройки разработчика
3. **Введите токен бота** от @BotFather
4. **Нажмите "Обновить токен"** - токен будет проверен и сохранен
5. **Проверьте статус** - должен отображаться зеленый индикатор "Активен"

### Структура токена

Токен должен иметь формат: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`

## 🔒 Безопасность

- **Токены шифруются** при сохранении в базе данных
- **Доступ только для разработчиков** - проверка роли на уровне API
- **Валидация токенов** - проверка через официальный Telegram API
- **Скрытие в интерфейсе** - поле ввода имеет тип `password`

## 🛠️ Технические детали

### Новая таблица `bot_settings`

```sql
CREATE TABLE "bot_settings" (
  "id" TEXT NOT NULL,
  "key" TEXT NOT NULL,
  "value" TEXT NOT NULL,
  "description" TEXT,
  "is_encrypted" BOOLEAN NOT NULL DEFAULT false,
  "created_at" TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
  "updated_at" TIMESTAMP(3) NOT NULL,
  CONSTRAINT "bot_settings_pkey" PRIMARY KEY ("id")
);
```

### Ключи настроек

- `telegram_bot_token` - токен Telegram бота
- Возможность добавления других настроек бота в будущем

### API Endpoints

#### GET `/api/settings/telegram/admin`
Возвращает текущие настройки бота и шаблоны уведомлений.

#### POST `/api/settings/telegram/admin`
Обновляет настройки бота.

**Параметры:**
```json
{
  "action": "update_bot_token",
  "data": {
    "botToken": "123456789:ABCdefGHIjklMNOpqrsTUVwxyz"
  }
}
```

## 🔄 Миграция с переменных окружения

Если у вас уже настроен токен в переменных окружения:

1. **Текущий токен** будет автоматически использоваться как fallback
2. **Новый токен** из базы данных имеет приоритет
3. **Обновите токен** через веб-интерфейс для перехода на новую систему

## 🐛 Устранение неполадок

### Ошибка "Bot token not configured"
- Убедитесь, что токен сохранен в базе данных
- Проверьте права доступа (роль DEVELOPER/ADMIN)

### Ошибка "Invalid bot token"
- Проверьте правильность токена от @BotFather
- Убедитесь, что бот активен

### Ошибка "Access denied"
- Убедитесь, что у вас есть роль DEVELOPER или ADMIN
- Выйдите и войдите в систему заново

## 📝 Логи

Все операции с токенами логируются в консоль:
- Инициализация сервиса
- Обновление токена
- Ошибки валидации
