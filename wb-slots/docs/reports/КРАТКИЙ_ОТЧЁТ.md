## 🚨 Критичные проблемы (требуют немедленного исправления)

### #1: Неправильная структура try-catch

**Строки 315-494:** Код использует `page` ВНЕ блока try, где создаётся браузер.

**ПРОБЛЕМА:**
```typescript
try {
  const { page } = await initBrowser();
} // ← try закрывается

// ❌ Код ВНЕ try - page может быть undefined!
const result = await doSomething(page);
```

**РЕШЕНИЕ:**
```typescript
try {
  const { page } = await initBrowser();
  const result = await doSomething(page); // ✅ Внутри try
} catch (error) {
  // обработка
}
```

---

### #2: Cookies не применяются к браузеру

**ПРОБЛЕМА:** `restoreSession()` читает cookies из БД, но не применяет их к browser context.

**РЕШЕНИЕ:**
```typescript
const sessionResult = await this.sessionManager.restoreSession(userId, page.context());

if (sessionResult.isValid && sessionResult.metadata?.cookies) {
  // ✅ Применяем cookies
  await page.context().addCookies(sessionResult.metadata.cookies);
}
```
