# 🤖 Пошаговая настройка Telegram бота для авторизации

## 🎯 Проблема
При нажатии "Авторизация через Telegram" открывается непонятный канал, потому что бот не настроен.

## ✅ Решение

### Шаг 1: Создание бота в BotFather

1. **Откройте Telegram** и найдите [@BotFather](https://t.me/BotFather)
2. **Отправьте команду** `/newbot`
3. **Введите имя бота** (например: "WB Slots Bot")
4. **Введите username бота** (например: "wb_slots_bot")
5. **Сохраните токен** который даст BotFather

### Шаг 2: Настройка Web App

1. **В BotFather** выберите вашего бота
2. **Отправьте команду** `/newapp`
3. **Выберите бота** для которого создаете Web App
4. **Введите название** (например: "WB Slots App")
5. **Введите описание** (например: "Авторизация в системе WB Slots")
6. **Загрузите иконку** (опционально)
7. **Введите URL Web App**: `https://yourdomain.com/auth/telegram`
8. **Сохраните настройки**

### Шаг 3: Настройка переменных окружения

Добавьте в ваш `.env` файл:

```env
# Замените на реальные данные вашего бота
TELEGRAM_BOT_TOKEN="1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
NEXT_PUBLIC_TELEGRAM_BOT_USERNAME="wb_slots_bot"
```

### Шаг 4: Проверка настройки

1. **Перезапустите приложение** после изменения .env
2. **Откройте страницу** `/auth/telegram`
3. **Нажмите "Открыть в Telegram"**
4. **Должен открыться ваш бот** с кнопкой Web App

## 🔧 Дополнительные настройки

### Настройка команд бота

В BotFather выполните:

```
/setcommands
@your_bot_username
start - Запустить приложение
help - Помощь
```

### Настройка описания бота

```
/setdescription
@your_bot_username
Авторизация в системе WB Slots. Нажмите /start для входа в приложение.
```

### Настройка приветственного сообщения

```
/setstart
@your_bot_username
Добро пожаловать в WB Slots! Нажмите кнопку ниже для входа в приложение.
```

## 🚨 Частые проблемы

### Проблема: Открывается непонятный канал
**Причина:** Неправильный username бота или бот не настроен
**Решение:** 
1. Проверьте username в BotFather
2. Убедитесь что `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME` правильный
3. Перезапустите приложение

### Проблема: Web App не открывается
**Причина:** Неправильный URL в настройках Web App
**Решение:**
1. Проверьте URL в BotFather: `/newapp`
2. URL должен быть: `https://yourdomain.com/auth/telegram`
3. Убедитесь что сайт доступен по HTTPS

### Проблема: Ошибка авторизации
**Причина:** Неправильный токен бота
**Решение:**
1. Проверьте токен в BotFather: `/mybots`
2. Убедитесь что `TELEGRAM_BOT_TOKEN` правильный
3. Перезапустите приложение

## 📱 Тестирование

### Локальное тестирование

1. **Используйте ngrok** для создания HTTPS туннеля:
   ```bash
   ngrok http 3000
   ```

2. **Обновите URL** в BotFather на ngrok URL:
   ```
   https://abc123.ngrok.io/auth/telegram
   ```

3. **Протестируйте** авторизацию

### Продакшн тестирование

1. **Убедитесь** что сайт доступен по HTTPS
2. **Проверьте** что все переменные окружения настроены
