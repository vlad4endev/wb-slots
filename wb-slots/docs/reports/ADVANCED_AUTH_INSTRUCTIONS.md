# 🚀 Инструкция по использованию продвинутой системы авторизации

## ✅ Что было создано

### 1. **Продвинутая система авторизации**
- 🔒 **AdvancedAuthManager** - централизованное управление сессиями
- 🛡️ **AdvancedAuthMiddleware** - многоуровневая защита
- 🌐 **AdvancedWBAuthService** - продвинутая WB авторизация
- 🗄️ **Расширенная база данных** с новыми моделями

### 2. **Новые API endpoints**
- `POST /api/auth/advanced` - создание сессий, валидация, WB авторизация
- `GET /api/auth/advanced` - статус сессии, события безопасности

### 3. **Тестовый интерфейс**
- 📱 **`/advanced-auth-test`** - веб-интерфейс для тестирования
- 🧪 **Тестовые скрипты** для проверки функциональности

## 🚀 Как запустить и протестировать

### Шаг 1: Запуск сервера
```bash
cd wb-slots
npm run dev
```

### Шаг 2: Открыть тестовый интерфейс
Перейдите в браузере по адресу:
```
http://localhost:3000/advanced-auth-test
```

### Шаг 3: Тестирование функций

#### 🔐 **Управление сессиями**
1. Введите User ID: `cmfvmlf4x0000pmjsmd3eouhu`
2. Нажмите **"Создать сессию"**
3. Скопируйте Session ID
4. Нажмите **"Валидировать"** для проверки

#### 🌐 **WB Авторизация**
1. Нажмите **"Запустить WB авторизацию"**
2. Дождитесь открытия браузера
3. Завершите авторизацию в WB
4. Нажмите **"Сохранить сессию"**

#### 🛡️ **Безопасность**
- Просматривайте статистику безопасности
- Отслеживайте события безопасности
- Мониторьте активные сессии

## 🧪 Быстрое тестирование через скрипт
