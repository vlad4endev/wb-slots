# 🔧 Решение ошибки 400 при сохранении токена Telegram

## 🚨 Проблема
```
POST /api/settings/telegram/admin 400 in 114ms
```

## 🔍 Диагностика показала:

1. **Ошибка 401 Unauthorized** - проблема с аутентификацией
2. **Роль пользователя изменена** на DEVELOPER ✅
3. **API endpoint работает** корректно ✅

## ✅ Решение

### Проблема: Отсутствие аутентификации
API endpoint требует аутентификации через cookies, но скрипты не передают их.

### Решение 1: Через браузер (рекомендуется)

1. **Откройте браузер** и перейдите на http://localhost:3000
2. **Войдите в систему** (если не авторизованы)
3. **Перейдите на страницу настроек Telegram:**
   ```
   http://localhost:3000/settings/telegram
   ```
4. **В разделе "Настройки разработчика":**
   - Вставьте токен Telegram бота
   - Нажмите "Сохранить токен"

### Решение 2: Через файл .env.local

1. **Создайте Telegram бота:**
   - Откройте [@BotFather](https://t.me/botfather)
   - Отправьте `/newbot`
   - Следуйте инструкциям
   - Скопируйте токен

2. **Отредактируйте `.env.local`:**
   ```env
   TELEGRAM_BOT_TOKEN="ваш_токен_здесь"
   ```

3. **Перезапустите сервер:**
   ```bash
   npm run dev
   ```

### Решение 3: Через API с cookies

Если хотите использовать API напрямую:

1. **Откройте браузер** и перейдите на http://localhost:3000
2. **Откройте Developer Tools** (F12)
3. **Перейдите на вкладку Network**
4. **Попробуйте сохранить токен** через интерфейс
5. **Найдите запрос** к `/api/settings/telegram/admin`
6. **Скопируйте cookies** из заголовков запроса
7. **Используйте cookies** в API запросах

## 📋 Пошаговая инструкция

### Шаг 1: Создание бота
1. Откройте [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте `/newbot`
3. Введите имя: `WB Slots Notifier`
4. Введите username: `wb_slots_notifier_bot` (уникальный)
5. Скопируйте токен

### Шаг 2: Сохранение токена
**Вариант A (через браузер):**
1. Откройте http://localhost:3000/settings/telegram
2. Вставьте токен в поле "Токен бота"
3. Нажмите "Сохранить токен"

**Вариант B (через файл):**
1. Откройте `.env.local`
2. Замените `TELEGRAM_BOT_TOKEN=""` на `TELEGRAM_BOT_TOKEN="ваш_токен"`
3. Перезапустите сервер

### Шаг 3: Проверка
1. Проверьте статус бота - должен быть зеленый
2. Попробуйте отправить тестовое сообщение
