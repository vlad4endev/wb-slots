# 🚀 Быстрый старт - Настройка Telegram уведомлений

## ✨ Новое! Кнопка "Получить ID"

Теперь получить Chat ID стало проще! В интерфейсе есть специальная кнопка.

## 📱 3 простых шага:

### Шаг 1: Откройте настройки
```
http://localhost:3000/settings → вкладка "Уведомления"
```

### Шаг 2: Получите Chat ID
1. Нажмите кнопку **"Получить ID"** (рядом с полем Chat ID)
2. Откроется бот [@chatIDrobot](https://t.me/chatIDrobot) в Telegram
3. Нажмите **START** в Telegram
4. Бот пришлет вам ваш Chat ID (число, например: `123456789`)
5. Скопируйте это число

### Шаг 3: Сохраните настройки
1. Вставьте Chat ID в поле
2. Включите галочку "Получать уведомления о найденных слотах"  
3. Нажмите **"Сохранить настройки"**

## ✅ Готово!

- Chat ID автоматически сохранился в базу данных
- При следующем визите настройки загрузятся автоматически
- Теперь вы будете получать уведомления о найденных слотах!

## 🔔 Что происходит дальше:

Когда система найдет подходящие слоты, вы получите уведомление:

```
🎯 Найдены подходящие слоты!

Обнаружено 2 слотов для бронирования

📍 Слот 1:
   🏪 Склад: Коледино
   📅 Дата: 2025-11-15
   💰 Коэффициент: 3
   📦 Типы коробок: 2, 5

...
```

## 💡 Важно знать:

### Токен бота - системная настройка
- **Обычные пользователи** настраивают только свой Chat ID
- **Токен бота** устанавливает только администратор
- Один бот работает для всех пользователей системы
- Каждый пользователь получает уведомления на свой Chat ID

### Настройки сохраняются автоматически
- После первого сохранения Chat ID остается в базе
- Не нужно вводить каждый раз
- Можно изменить только если сменился аккаунт Telegram

## 🛠️ Альтернативные способы

### Через скрипт (для разработчиков):
```bash
node setup-telegram-notifications.js <USER_ID> <CHAT_ID>
```

### Через API:
```bash
curl -X POST http://localhost:3000/api/settings/telegram/user \
  -H "Content-Type: application/json" \
  -d '{"chatId": "123456789", "enabled": true}'
```

## ❓ Проблемы?

### Уведомления не приходят
1. Убедитесь, что вы нажали START в боте
2. Проверьте, что Chat ID правильный
3. Убедитесь, что настройки сохранены (галочка включена)

### Не знаете User ID
```bash
# Получить текущего пользователя
curl http://localhost:3000/api/auth/me
```

### Бот не отвечает
Убедитесь, что администратор установил `TELEGRAM_BOT_TOKEN` в переменных окружения.
