# 🔧 Решение проблем с Docker

## Проблемы, которые были исправлены:

### 1. ❌ Несовместимость версии Node.js
**Проблема:** Vite требует Node.js ^20.19.0 || >=22.12.0, а у вас 18.20.8

**Решение:**
- Обновлен Dockerfile с Node.js 20
- Добавлены предупреждения о версии Node.js

### 2. ❌ Проблемы с Puppeteer
**Проблема:** Не может скачать Chrome из-за сетевых проблем

**Решение:**
- Добавлен `PUPPETEER_SKIP_DOWNLOAD=true`
- Установлен Chromium в Alpine Linux
- Настроен `PUPPETEER_EXECUTABLE_PATH`

### 3. ❌ Конфликты Prisma engines
**Проблема:** Ошибки при очистке node_modules

**Решение:**
- Улучшен процесс сборки Docker
- Добавлен .dockerignore для оптимизации

## 📋 Что делает исправление:

1. **Останавливает** все Docker контейнеры
2. **Очищает** Docker кэш и образы
3. **Обновляет** Dockerfile с Node.js 20
4. **Настраивает** Puppeteer для работы с Chromium
5. **Создает** дополнительные файлы для разработки
6. **Предлагает** альтернативные способы запуска

## 🔄 Альтернативные способы запуска:

### 1. Локальная разработка (рекомендуется)
- Только БД и Redis в Docker
- Приложение запускается локально
- Быстрее и проще для разработки

```batch
start-local-dev.bat
```

### 2. Полностью локальный запуск
- Без Docker вообще
- Требует установки PostgreSQL и Redis
- Максимальная производительность

### 3. Обновление Node.js
- Скачайте Node.js 20.x с https://nodejs.org/
- Переустановите проект
- Используйте обычные Docker команды

## 🛠️ Созданные файлы:
